# v1.7.1-rc.1 Release Preparation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cut and publish the `v1.7.1-rc.1` pre-release tag so GoReleaser produces a GitHub pre-release and Docker image for the security-fix patch.

**Architecture:** All changes are already on `main`. The only work is updating `CHANGELOG.md` to version the unreleased section, committing, tagging, and pushing. GoReleaser handles binary builds, GitHub Release creation, and Docker push automatically on tag push.

**Tech Stack:** Git, GitHub Actions, GoReleaser, GHCR Docker registry

---

### Task 2: Tag and Push RC

**Files:** none (git metadata only)

- [ ] **Step 1: Create annotated tag**

```bash
git tag -a v1.7.1-rc.1 -m "Release candidate v1.7.1-rc.1"
```

- [ ] **Step 2: Push tag to origin**

```bash
git push origin v1.7.1-rc.1
```

Expected output:

```
To https://github.com/askdba/mysql-mcp-server
 * [new tag]         v1.7.1-rc.1 -> v1.7.1-rc.1
```

- [ ] **Step 3: Verify the release pipeline triggered**

```bash
gh run list --workflow=release.yml --limit=3
```

Expected: a new run in `queued` or `in_progress` state for the `v1.7.1-rc.1` tag.

### Task 3: Watch CI and Validate Release

**Files:** none

- [ ] **Step 1: Monitor the release workflow**

```bash
gh run watch $(gh run list --workflow=release.yml --limit=1 --json databaseId --jq '.[0].databaseId')
```

Wait for all jobs to show `✓`. The workflow runs: unit tests, integration tests (MySQL 8.0/8.4/9.0, MariaDB 11.4), GoReleaser binary builds, Docker image push.

- [ ] **Step 2: Confirm GitHub pre-release was created**

```bash
gh release view v1.7.1-rc.1
```

Expected: release is marked **Pre-release**, has attached binaries for linux/amd64, darwin/amd64, darwin/arm64, windows/amd64.

- [ ] **Step 3: Confirm Docker image pushed**

```bash
gh api /orgs/askdba/packages/container/mysql-mcp-server/versions --jq '.[0].metadata.container.tags'
```

Expected: `["v1.7.1-rc.1"]` (or similar list including the new tag).
